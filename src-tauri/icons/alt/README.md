# Alternate icon directions

Six complete, ready-to-promote icon sets from the 2026-10 logo-genre exploration.
None of them is live: the app still uses `../icon-source.svg` (the throughput
pulse). Each directory here holds a **full Tauri icon ladder** in exactly the
same layout as `../`, generated from its own hand-authored 1024×1024 SVG —
promoting one is a copy operation, not a redesign.

|Dir|Name / genre|One-line worldview|16 px vs current|
|---|---|---|---|
|`telemetry/`|TELEMETRY 遥测 · 航天仪表派|the desktop is ground control; every tab is an agent in orbit, the white arc its telemetry trail|on par|
|`phosphor/`|PHOSPHOR 磷光 · CRT 纪念碑派|a monument to the terminal prompt (`❯ ▉`) where coding agents were born; the ghosts are parallel tabs|weaker|
|`sigil/`|SIGIL 术印 · 几何符印派 ⭐|every spawn is a summoning; the gold ring seals π itself — omp's totem, two gold seals (agents) and one orange (you)|**stronger**|
|`bauhaus/`|BAUHAUS 构成 · 原色构成派|π is three strokes — black beam, blue leg, red leg, plus a yellow sun|**stronger**|
|`biolume/`|BIOLUME 深蓝共振 · 生物发光派|the desktop is a deep-sea viewing window; the core is the agent you lit, the sparks its symbionts|weaker|
|`kamon/`|KAMON 井桁 · 家纹派|the igeta (well) crest: where everything draws water, the command line's `#`, the tab grid; one orange drop = the living agent|**stronger**|

All six passed the exploration gate: 256/64/32/16 px render check, a true
16 px pixel-grid check (8× device scale, compared against the incumbent), a
light-background check, and a collision sweep against VSCode / Cursor /
Copilot / Warp / Claude / Zed / Raycast. SIGIL is the recommended pick
(π ties directly to oh-my-pi, strongest small size); KAMON is the runner-up.

## Layout of each directory

Identical to `../` plus two source files:

- `icon-source.svg` — the source of truth (hand-authored, 1024 grid)
- `master.png` — 1024×1024 raster of the source (what `tauri icon` consumed)
- `wrap.html` — the one-line page used to re-rasterize (see below)
- `16x16.png`, `512x512.png` — the two sizes the Tauri CLI does not emit
  (same role as in `../`: favicon/external use and stores/docs)
- everything else (`32x32.png`, `128x128.png`, `128x128@2x.png`, `icon.png`,
  `icon.ico`, `icon.icns`, `Square*Logo.png`, `StoreLogo.png`, `android/`,
  `ios/`) — generated by `npx tauri icon master.png -o .`

`phosphor/` is the only set with transparent corners (CRT glass rounding,
rx 150); the other five are full-bleed squares.

## Regenerating a set

```bash
cd src-tauri/icons/alt/<name>
# 1. edit icon-source.svg, then re-rasterize (transparent-safe):
chrome --headless --disable-gpu --hide-scrollbars --default-background-color=00000000 \
  --window-size=1024,1024 --screenshot="$(pwd -W)/master.png" "file:///$(pwd -W)/wrap.html"
# repeat with --window-size=512,512 → 512x512.png and 16,16 → 16x16.png
# 2. rebuild the ladder:
npx tauri icon master.png -o .
```

(The paths above assume Git Bash on Windows; adapt `pwd -W` elsewhere.)

## Promoting a direction to the live app icon

1. Copy every file except `wrap.html` from `alt/<name>/` over `src-tauri/icons/`
   (`icon-source.svg`, `master.png` included, so `../README.md`'s pipeline
   keeps describing the truth).
2. `tauri.conf.json` needs no change — the promoted set already carries the
   exact filenames it references.
3. Mind the rebuild trap in `../README.md`: cargo does not re-embed a changed
   `icon.ico` on its own —
   `rm -rf src-tauri/target/release/build/omp-desktop-* && touch src-tauri/build.rs`
   before `npm run build`, and eyeball the exe's icon as documented there.
4. Add a `CHANGELOG.md` line under `[Unreleased]`.
